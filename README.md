# Bulut İçin Vergi Beyannamesi

> **Resmi uyarı:** Bu yazılım bir kümülüsü tüzel kişi sayar. Gök yüzü itiraz ederse lütfen issue açın, yağmur yağdırmayın.

## Bu nedir?

Dünya tarihinde ilk kez bir **bulut** için gelir vergisi, yağmur stopajı, gölge amortismanı ve güneş ışığı KDV'si hesaplayan çalışan bir Python motoru.

Neden? Çünkü bulutlar yıllardır ücretsiz gölge dağıtıyor, yağmur satıyor ve hiç fatura kesmiyor. Devlet (yani bu repo) artık duruyor.

## Kurulum

```bash
python3 bulut_beyanname.py
```

Bağımlılık yok. Sadece Python 3 ve vicdan.

## Kullanım

Program sizden şunları ister:
- Bulutun adı (varsayılan: Ahmet Kümülüs)
- Yükseklik (metre)
- Bu ay yağdırdığı litre
- Kaç dakika gölge verdiği

Sonra size **resmi görünümlü** bir beyanname basar. Ödemeyi gökyüzüne havale edin.

## Yasal dayanak (uydurma)

Madde 1 — Bulut, nem toplayarak ekonomik faaliyet yürütür.
Madde 2 — Gölge bir hizmettir, hizmet KDV'ye tabidir.
Madde 3 — Yağmur stoktan çıkıştır, stopaj uygulanır.
Madde 4 — Bu maddeler şaka ile ciddiyet arasında asılı durur.
